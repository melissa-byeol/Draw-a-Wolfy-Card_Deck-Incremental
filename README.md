# Draw a Wolfy Card: Deck Incremental

Un juego incremental donde revelas cartas de una baraja de 20 cartas. Cada carta revela un Lobito que genera dinero. Cuando se acaban las cartas, un Lobito invisible las baraja y el ciclo comienza de nuevo.

## Cómo jugar

1. Haz click en la baraja para revelar una carta
2. Cada Lobito revela genera dinero ($1 o más según rareza)
3. Las cartas se acumulan en la mesa
4. Cuando se agotan las 20 cartas, el Lobito invisible las baraja
5. ¡Descubre todas las cartas y completa tu Carddex!

## Cartas disponibles

- **Lobito** [1/2] - $1
- **Lobito Arquero** [1/4] - $2

## Características

- Sistema de rarezas automático
- Carddex para coleccionar cartas descubiertas
- Animaciones suaves
- Ciclo infinito de barajado
