# Draw a Wolfy Card: Deck Incremental

Un juego incremental donde revelas cartas de una baraja de 20 cartas. Cada carta revela un Lobito que genera dinero. Cuando se acaban las cartas, un Lobito invisible las baraja y el ciclo comienza de nuevo.

## Cómo jugar

1. Haz click en la baraja para revelar una carta
2. Cada Lobito revela
